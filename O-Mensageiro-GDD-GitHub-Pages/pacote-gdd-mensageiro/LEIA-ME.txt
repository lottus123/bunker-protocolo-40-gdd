COMO PUBLICAR O NOVO GDD

Repositório:
https://github.com/lottus123/bunker-protocolo-40-gdd

1. Abra o repositório e permaneça na branch "main".
2. Apague o index.html antigo.
3. Envie TODO o conteúdo da pasta PUBLICAR_NO_GITHUB para a raiz:
   - index.html
   - pasta assets
4. Confirme o commit com a mensagem:
   Publica novo GDD de O Mensageiro
5. Abra Settings > Pages.
6. Em Build and deployment, use:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
7. Aguarde de 1 a 3 minutos e abra:
   https://lottus123.github.io/bunker-protocolo-40-gdd/

IMPORTANTE

- Não envie a pasta PUBLICAR_NO_GITHUB em si.
- Envie os arquivos que estão DENTRO dela.
- A pasta BACKUP_SITE_ANTIGO contém a versão anterior.
- O Firebase usa a sala nova "o-mensageiro-gdd-v1".
- Alterações feitas no GDD são sincronizadas em tempo real.
